بخش دوم: معرفی پروژه

سامانه مدیریت اطلاعات دانشجو، یک وب‌سایت فارسی است که با هدف ثبت، ذخیره‌سازی، جستجو، ویرایش و حذف اطلاعات دانشجویان طراحی شده است. کاربران می‌توانند اطلاعات دانشجویان را از طریق یک فرم وارد کنند و پس از ثبت، در بخش جستجو به اطلاعات ذخیره‌شده دسترسی داشته باشند.

اطلاعات ثبت‌شده در این سامانه شامل شماره دانشجویی، نام و نام خانوادگی، رشته تحصیلی، مقطع تحصیلی و شماره تماس است. این اطلاعات در پایگاه داده ذخیره می‌شوند تا امکان بازیابی و جستجوی آن‌ها در مراجعات بعدی نیز فراهم باشد.

هدف اصلی این پروژه، آشنایی عملی با طراحی صفحات وب، ایجاد فرم‌های ورود اطلاعات، برقراری ارتباط میان رابط کاربری و سرور و ذخیره‌سازی اطلاعات در پایگاه داده است.

بخش سوم: معرفی قالب و ظاهر سایت

رابط کاربری این سامانه با استفاده از HTML و CSS طراحی شده است. از آنجا که سایت به زبان فارسی است، چیدمان صفحات به‌صورت راست‌چین (RTL) در نظر گرفته شده تا نمایش متن‌ها، فرم‌ها و سایر اجزای رابط کاربری با زبان فارسی سازگار باشد.

در قسمت بالای صفحه، عنوان سامانه و منوی ناوبری قرار گرفته‌اند. بخش اصلی صفحه از دو قسمت تشکیل شده است: قسمت اول به ثبت اطلاعات دانشجویان اختصاص دارد و قسمت دوم امکان جستجو و مشاهده نتایج را فراهم می‌کند.

در طراحی ظاهری سایت، از رنگ‌های هماهنگ، پنل‌های مجزا، دکمه‌های مشخص و جدول برای نمایش اطلاعات استفاده شده است. همچنین تلاش شده است طراحی صفحات ساده و قابل‌فهم باشد تا کاربران بتوانند به‌راحتی از امکانات سامانه استفاده کنند.

بخش چهارم: ساختار فرم ورود اطلاعات

فرم ثبت اطلاعات دانشجو شامل پنج فیلد اصلی است که هرکدام برای دریافت نوع مشخصی از اطلاعات طراحی شده‌اند.

۱. شماره دانشجویی
این فیلد برای ثبت شماره اختصاصی هر دانشجو استفاده می‌شود. مقدار واردشده به‌صورت رشته متنی دریافت می‌شود تا قالب شماره دانشجویی حفظ شود.

۲. نام و نام خانوادگی
این فیلد برای دریافت نام کامل دانشجو در نظر گرفته شده است. در صورت نیاز به تطبیق با ساختار داده‌های بک‌اند، اطلاعات واردشده به دو مقدار مجزای نام و نام خانوادگی تقسیم می‌شوند.

۳. رشته تحصیلی
این فیلد به‌صورت فهرست انتخابی طراحی شده است تا کاربر بتواند رشته تحصیلی دانشجو را از میان گزینه‌های موجود انتخاب کند. این گزینه‌ها می‌توانند شامل مهندسی کامپیوتر، مهندسی برق، مهندسی مکانیک، مدیریت صنعتی و علوم کامپیوتر باشند.

۴. مقطع تحصیلی
این فیلد نیز به‌صورت فهرست انتخابی طراحی شده و گزینه‌هایی مانند کاردانی، کارشناسی، کارشناسی ارشد و دکتری را در بر می‌گیرد.

۵. شماره تماس
این فیلد برای ثبت شماره تلفن دانشجو استفاده می‌شود. شماره تماس به‌صورت رشته متنی ذخیره می‌شود تا صفر ابتدایی شماره تلفن حفظ شود.

پس از تکمیل فرم، کاربر با انتخاب دکمه «ثبت اطلاعات»، داده‌های واردشده را ارسال می‌کند. در این مرحله، JavaScript اطلاعات فرم را دریافت کرده و در قالب داده‌های JSON به بک‌اند می‌فرستد. سپس بک‌اند داده‌های دریافتی را پردازش و اعتبارسنجی می‌کند و در صورت معتبر بودن، آن‌ها را در پایگاه داده MySQL ذخیره می‌کند.

پس از ثبت موفق اطلاعات، پیام مناسبی به کاربر نمایش داده می‌شود. همچنین فهرست دانشجویان به‌روزرسانی می‌شود تا اطلاعات دانشجو جدید در جدول قابل مشاهده باشد.

بخش پنجم: عملکرد جستجو

بخش جستجوی سامانه با هدف دسترسی سریع به اطلاعات دانشجویان ثبت‌شده طراحی شده است. کاربر می‌تواند عبارتی مانند نام دانشجو، شماره دانشجویی یا رشته تحصیلی را در کادر جستجو وارد کند.

پس از انتخاب دکمه «جستجو»، JavaScript درخواست مربوطه را به بک‌اند ارسال می‌کند. بک‌اند با بررسی اطلاعات ذخیره‌شده در پایگاه داده، رکوردهای مرتبط با عبارت جستجو را پیدا کرده و نتایج را به رابط کاربری بازمی‌گرداند.

نتایج جستجو در قالب یک جدول نمایش داده می‌شوند. این جدول شامل شماره ردیف، شماره دانشجویی، نام و نام خانوادگی، رشته تحصیلی، مقطع تحصیلی، شماره تماس و عملیات مربوط به هر رکورد است.

در صورتی که هیچ اطلاعاتی مطابق با عبارت جستجو پیدا نشود، سامانه پیام مناسبی به کاربر نمایش می‌دهد تا مشخص شود نتیجه‌ای برای جستجوی انجام‌شده وجود ندارد.

این بخش امکان بازیابی اطلاعات ثبت‌شده را فراهم می‌کند و به کاربران اجازه می‌دهد در مراجعات بعدی نیز به‌سادگی به اطلاعات موردنظر خود دسترسی داشته باشند.

بخش ششم: فناوری‌های پیاده‌سازی

Frontend:

  • HTML: برای ایجاد ساختار اصلی صفحه وب، طراحی فرم ثبت اطلاعات، تعریف فیلدهای ورودی، ایجاد دکمه‌ها و نمایش جدول نتایج استفاده شده است.
  • CSS: برای طراحی ظاهر سایت، تعیین رنگ‌ها، تنظیم فاصله‌ها، چیدمان پنل‌ها، استایل‌دهی به فرم‌ها و جدول و پشتیبانی از نمایش راست‌چین متن‌های فارسی به کار رفته است.
  • JavaScript: برای ایجاد تعامل با کاربر، دریافت اطلاعات فرم، انجام اعتبارسنجی اولیه، ارسال درخواست به سرور، دریافت پاسخ و به‌روزرسانی جدول نتایج استفاده می‌شود.

Backend:

  • Go: زبان برنامه‌نویسی بخش بک‌اند است که درخواست‌های دریافتی از رابط کاربری را پردازش می‌کند و عملیات مربوط به ثبت، بازیابی، ویرایش و حذف اطلاعات دانشجویان را بر عهده دارد.
  • Docker/Docker compose: برای اجرای سرویس بک‌اند و پایگاه داده در محیط توسعه استفاده می‌شوند. این ابزارها فرایند راه‌اندازی و مدیریت سرویس‌های موردنیاز پروژه را ساده‌تر می‌کنند.
  • Swagger UI: در صورت فعال بودن در پیکربندی پروژه، برای مشاهده مستندات API و آزمایش مسیرهای ارتباطی سرور استفاده می‌شود.

Database:

  • MySQL: به‌عنوان پایگاه داده سامانه استفاده می‌شود و اطلاعات دانشجویان را ذخیره می‌کند. به کمک این پایگاه داده، اطلاعات ثبت‌شده در درخواست‌های بعدی نیز قابل بازیابی خواهند بود.

نحوه ارتباط اجزای سامانه

ارتباط میان اجزای مختلف پروژه به این صورت است که کاربر ابتدا اطلاعات موردنظر را در فرم HTML وارد می‌کند. سپس JavaScript این اطلاعات را از طریق درخواست HTTP به بک‌اند ارسال می‌کند. بک‌اند پس از پردازش درخواست، اطلاعات را در پایگاه داده MySQL ذخیره می‌کند یا اطلاعات موردنیاز را از آن بازیابی می‌کند. در نهایت، نتیجه پردازش به رابط کاربری بازگردانده می‌شود و اطلاعات در جدول سایت نمایش داده می‌شوند.

بخش هفتم: نتیجه‌گیری

در این پروژه، یک سامانه تحت وب برای ثبت، ذخیره‌سازی و جستجوی اطلاعات دانشجویان طراحی شده است. این سامانه شامل فرمی برای ورود اطلاعات و بخشی برای جستجو و نمایش نتایج است. اطلاعات واردشده توسط کاربر از طریق JavaScript به بک‌اند ارسال می‌شوند و پس از پردازش، در پایگاه داده MySQL ذخیره می‌شوند.

پیاده‌سازی این پروژه فرصتی برای آشنایی عملی با طراحی صفحات وب، ایجاد فرم‌های HTML، استایل‌دهی با CSS، برنامه‌نویسی JavaScript، برقراری ارتباط با API، استفاده از متدهای HTTP و ذخیره‌سازی اطلاعات در پایگاه داده فراهم کرده است.

از جمله چالش‌های احتمالی در پیاده‌سازی این سامانه می‌توان به هماهنگ‌سازی ساختار داده‌های ارسالی از فرانت‌اند با فیلدهای مورد انتظار بک‌اند، تنظیم صحیح آدرس API، برقراری ارتباط با پایگاه داده، مدیریت خطاهای مربوط به ثبت اطلاعات و تطبیق نتایج جستجو با ساختار پاسخ سرور اشاره کرد.

در مجموع، این پروژه نشان می‌دهد که چگونه می‌توان با استفاده از فناوری‌های رایج توسعه وب، سامانه‌ای ساده و کاربردی برای مدیریت اطلاعات دانشجویان ایجاد کرد. همچنین، اجرای آن درک بهتری از ارتباط میان رابط کاربری، منطق سمت سرور و پایگاه داده فراهم می‌کند و زمینه مناسبی برای توسعه پروژه‌های پیچیده‌تر در آینده به وجود می‌آورد.
